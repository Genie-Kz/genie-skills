# このフォルダに回答が保存されます

HTML を Edge か Chrome で開き、上部の「保存先を選ぶ」で、このフォルダを選んでください（ほかのブラウザでは保存できません）。保存されると、上部にチェックと「answers に保存済み」、保存した時刻が出ます。この表示を押すと、その場で保存します。答え終わったら、エージェントに「回答した」と伝えてください。

回答はブラウザの中にも残るので、保存の途中で閉じても、次に開いて保存先を選べばフォルダに書き直されます。手元とフォルダの回答が違うときは、残す方を選ぶ画面が出ます。ブラウザの中にも残せなかったときだけ、閉じる前にブラウザが確認します。

各セクションの末尾で「このセクションにコメント」を押すと、文章と画像を入力できます。資料全体に伝えたいことは左下の「全体へのコメント」を開いて「全体にコメント」に書いてください。

別の話題を始めるには、左の一覧の「追加したセクション」の「＋」で題名と本文を入れ、「セクションを追加」を押します。あとから直すときは、題名の右を「編集」に切り替え、題名や本文を押して書き換えます。

エージェントが作ったセクションで今回選ぶ判断がなければ、左の一覧のチェック欄を押して了承できます。過去の判断がすべて「決定事項」に移ったページでも使えます。狭い画面ではページ末尾の「このセクションはOK」を使います。もう一度押すと了承を取り消せます。書いたコメントや画像は残ります。

了承したあと、次の回でそのセクションの未完了の項目に返事や対応が付くと、チェックが外れます。「この回の返事」の左の矢印を押すと、該当する返事へ移動できます。確認したら、もう一度「このセクションはOK」を押してください。

`.edition.json` は、次の回の資料ができたことを開いている資料に知らせるファイルです。保存先をつないで資料を開いていれば、回答の保存が終わると自動で新しい回を開きます。この画面で書きかけているときは、上部に「更新」が出ます。ボタンにカーソルを乗せると、どの欄を書いているか分かり、押すと新しい回で続きを書けます。チャットなど別のウィンドウに移っていれば、書きかけを残したまま自動で新しい回を開きます。

## キーボード操作

visual-consensus で作った資料をブラウザーで開くと、次のキーを使えます。表の `Ctrl` は Mac では `⌘`（Command）です。

| キー | 操作する場所 | 動作 |
| --- | --- | --- |
| `Ctrl+S` | 資料全体 | 回答を保存する。初めて保存するときは保存先を選ぶ。 |
| `Ctrl+Enter` | コメント、セクションの題名・本文 | 入力を確定する。新しいセクションは、題名を入力してあれば追加する。 |
| `Esc` | 入力欄 | セクションの編集中の欄や画像名の変更を取り消す。コメントは内容を保って閉じる。 |
| `Esc` | メニュー・画像ビューア・削除の確認 | メニューや画像を閉じる。削除の確認ではキャンセルする。印の位置を指定中なら配置を取り消し、印を編集中なら編集欄を閉じる。 |
| `Ctrl+E` | 追加したセクション | 表示中のセクションの「閲覧」と「編集」を切り替える。 |
| `Enter` または `Space` | 「編集」にしたセクションの題名・本文 | フォーカスのある欄の編集を始める。 |
| `Enter` または `Tab` | セクションの題名、画像の名前 | 題名の入力中は本文へ移る。画像名の入力中は名前を確定する。 |
| `Ctrl+B` | 書式ボタンのある入力欄 | 太字を切り替える。 |
| 行頭で `-` に続けて `Space` | 書式ボタンのある入力欄 | 箇条書きを始める。 |
| `Ctrl+V` | 書式ボタンのある入力欄、セクション | コピーした画像を入力位置に貼る。欄の外ではセクションに添付する。 |
| `Ctrl+Z` | 書式ボタンのある入力欄 | 直前の編集を元に戻す。本文から消した画像も戻せる。 |
| `Enter` または `Space` | 画像ビューアの画像 | ピンを置く位置の指定を始める。位置の指定中にもう一度押すと確定する。 |
| `+`・`-`・`0` | 画像ビューア（入力欄の外） | 画像を拡大・縮小・100%に戻す。ホイール操作や右上のボタンでも倍率を変えられる。 |
| `Space` を押しながらドラッグ／中ボタンドラッグ | 拡大中の画像ビューア | 画像を移動する。右上の「移動」ボタンを押して左ドラッグでも移動できる。 |
| `矢印キー`、`Shift`＋`矢印キー` | 画像の印の位置を指定中 | 照準を動かす。`Shift` を押しながら動かすと移動幅が10倍になる。 |
| `Delete` または `Backspace` | 画像上の印 | フォーカスのあるピンや範囲を削除する。 |
| `↓`・`↑`、`Home`・`End` | 「資料と保存のメニュー」 | メニューボタンで `↓`・`↑` を押すと開く。開いたら上下で項目を選び、`Home`・`End` で先頭・末尾に移る。`Tab` でメニューを閉じて先へ進む。 |
| `Ctrl+C` | 「回答をコピー」の手動コピー画面 | 全文を選んでコピーすると管理番号と画像の座標も含まれる。一部を選ぶと選択した本文だけをコピーする。 |

## 回答を受け取ったら

`answers.md` の先頭で資料の題名と回を確かめてください。続いて資料の順に、セクションごとの判断、コメント、画像の説明と印が並びます。複数のセクションで使う画像は最初のセクションにまとめ、関係するほかのセクション名も記載します。資料全体へのコメントは「全体へのコメント」、利用者が作ったセクションの本文は「利用者が追加したセクション」にあります。確定した内容は末尾の「決定事項」で確認できます。

利用者が「完了」を押した項目は「決定事項」の「完了したもの」に載ります。行末の「完了」を確認し、次の回で同じことを問い直さないでください。「✓ 対応済み（第N回）」はエージェントが対応した回を示します。

| セクションの見出しの状態 | 回答の読み方 |
| --- | --- |
| 判断済み（コメントのない行は了承） | 利用者がすべての判断に答えました。無記入の行は了承として進めます。 |
| 保留あり（D4 など） | 括弧内の判断は保留です。無記入の行と未回答の判断は未確認のままです。 |
| 未確認の判断あり（コメントのない行は未確認） | 「未回答」の判断と無記入の行は未確認です。決める必要があれば、その判断や行を示して利用者に聞き返してください。 |
| 了承 | 選ぶ判断のないセクションで、利用者が「このセクションはOK」を押しました。コメントがあれば、その内容も反映します。 |
| 記入あり（コメントのない行は未確認） | 選ぶ判断のないセクションに、一部のコメントがあります。残りの行を進める判断が必要なら利用者に聞き返してください。 |
| 手を付けていないセクション | まだ選択・了承・記入のないセクションを末尾に列挙します。いずれも未確認です。 |

ピンや範囲を確かめるときは、該当行の `images/marks/<画像ID>.png` をこのフォルダから開きます。丸の番号を行の「ピン1」「範囲2」などと照合してください。座標は原画像の左上を `(0, 0)`、右下を `(1, 1)` とした割合です。最後の印を消して保存すると、その印付き PNG も消えます。「回答をコピー」で渡された文面では、図名・番号と座標で場所を特定してください。

## 画像と回答の番号

本文に貼った画像には、画像の下の「名前を付ける」から名前を付けられます。例えば「一覧画面」と付けておくと、本文に「画像『一覧画面』の右上」と書いて、その画像を指せます。セクションの末尾の画像でも同じ名前を編集できます。

資料全体へのコメントは `answers.json` の `sections.general` に入り、`answers.md` の行頭は `全体` です。利用者が作ったセクションは S-01 のような番号で見つけられます。画像は `images/U-xx.png`、印の座標は `answers.json` にあります。使われている追加画像は JSON の `attachments` に載っています。各画像の `name` は1行・40文字までで、空文字は名前なしです。JSON の本文は `![U-01]` の形で画像を参照します。名前があれば `answers.md` とコピーでは `![U-01「一覧画面」]`、新しいセクションの末尾では ` ／ 画像「一覧画面」 images/U-01.png` と読めます。画像の説明や印の行には `図「一覧画面」` と載ります。
